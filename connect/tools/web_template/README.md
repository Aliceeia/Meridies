# Meridies, web copy

Plain website files (HTML, CSS, JS, JSON, images, audio) plus one small Python function for the live AI calls.
Generated by `connect/tools/export_web.py`. Don't edit files here: edit `connect/frontend/` and export again.

## What's in here

| Path | What |
|---|---|
| `index.html` | Meri, the voice assistant (home) |
| `gallery.html` | the digital gallery of memories |
| `walk.html` | walking through a scanned place |
| `live.html` | the hat's live view (needs the hat; shows "No hat data" on the web) |
| `css/` | one stylesheet per page, plus the walk overlay |
| `js/` | the page scripts, unchanged, plus `static-api.js` (see below) |
| `assets/` | logo |
| `data/api/` | the server's read-only answers, saved per demo viewer (User A, User B) |
| `data/` | scene samples, the yard floor plan and its top-down image |
| `media/memories/<id>/` | each memory's recording, cover and description images |
| `media/views/` | first-person scan views for the walk |
| `media/voice/` | prepared Gemini voice lines (MP3) |
| `api/index.py` | the Vercel function: runs the repo's own server code for the live calls |
| `api/_app/` | its copy of `connect/` (server, backend, plans, memory records, small scan views) |
| `vercel.json` | clean URLs (`/gallery`, `/walk`, `/live`) and the `/api/*` route to the function |
| `dev_server.py` | run all of it locally, the way Vercel serves it |

`js/static-api.js` loads first on every page. It answers the pages' read-only requests from `data/api/`,
points recordings, images and prepared voice lines at `media/`, and sends only these to the function:

| Call | Uses |
|---|---|
| `POST /api/meri/chat` | Meri's answers (Gemini over the saved memories and places) |
| `POST /api/hear` | transcribes a spoken command when the browser can't |
| `POST /api/tell-me-more` | describes a spot from its scan view and the notes left there |
| `GET /api/around` | what's around a spot (no AI) |
| `GET /api/voice` | speaks a new line in Meri's voice (Gemini TTS) |

Anything that would change data (recording, sharing, circles, settings) answers 403: the web copy is read-only.

## Run locally

```
python dev_server.py
```

Open http://localhost:8080. The AI calls read `GEMINI_API_KEY` from the environment, or from the `.env` above
the repo when this folder sits inside it. Needs Pillow only for "tell me more" in the yard.

## Deploy to Vercel

1. Install the CLI once: `npm i -g vercel`, then `vercel login`.
2. From this folder: `vercel` (first time: accept the defaults; framework "Other", no build command).
3. Add the key: `vercel env add GEMINI_API_KEY` (choose Production and Preview), optionally `GEMINI_MODEL`.
4. Ship it: `vercel --prod`.

`web/` is generated and Git-ignored. To use Git-based deployment, run the exporter in
your build workflow; otherwise deploy this local output directory with the CLI.

## Keep in mind

- **Everything exported is public once deployed.** The exporter includes only memories explicitly marked
  `community` that are not drafts or pending/rejected sharing requests. Private and family/MeriCircle
  memories and their media are excluded. The account switch is a demo, not authentication.
- Circle memberships, family-link tokens, review reports and personal settings are excluded. Voice clips
  are restricted to an allowlist derived from public scene text and the included public memory text.
- Keep `web/`, `.env` and local caches out of Git. The exporter fails closed if non-public records are
  passed into the function or memory-media packager.
- The data is a snapshot from the moment of export. Record new memories with the local server, then run
  `python connect/tools/export_web.py` again and redeploy.
- Each new spoken line costs one Gemini TTS call; prepared lines in `media/voice/` cost nothing.
- Family links (`/f/<token>`) and the hat's live streams need the local server.

## Public demonstration samples

Run `python connect/tools/export_web.py --demo-samples` from the repository root.
This adds independent copies of verified fictional scripts from `seed_samples.py`,
with new IDs and explicit Scripted demo labels. Source Mongo records, private
visibility and real circle memberships are never changed. The MeriCircle tab
illustrates sharing with these public fictional samples; it is not private access.
